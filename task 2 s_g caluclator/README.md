📝 Student Grade Calculator

🚀 A Java program to calculate a student's total marks, average percentage, and grade.

📊 Features

- 📚 Takes marks obtained in each subject.
- ➕ Calculates total marks.
- 📈 Calculates average percentage.
- 🏆 Assigns a grade based on the percentage.
- 📋 Displays the final results.

🛠️ Technologies Used

☕ Java | ⌨️ Scanner | 🔀 Conditional Statements
