🏦 ATM Interface

✨ A simple and user-friendly Java ATM Interface designed to perform basic banking operations with a clean and easy-to-use interface.

🌟 Features

💳 Check Balance – View the current account balance.
💰 Withdraw Money – Withdraw money securely.
💵 Deposit Money – Deposit money into the account.
🔐 Change PIN – Change the ATM PIN securely.
🔑 PIN Verification – Protect transactions with PIN authentication.
✅ Transaction Validation – Prevent invalid transactions and insufficient-balance withdrawals.

🛠️ Technologies Used

☕ Java
🧩 Object-Oriented Programming
⌨️ Scanner
🔀 Conditional Statements
🔄 Loops

🎨 User Experience

✨ Simple and attractive interface
🔒 Secure PIN-based access
⚡ Easy navigation
💡 Beginner-friendly design
