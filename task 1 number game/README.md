🎯 Number Game

🚀 A simple Java-based number guessing game.

🎲 Features

- 🔢 Generates a random number between 1 and 100.
- ⌨️ Takes the user's guess as input.
- 📈 Shows whether the guess is too high or too low.
- ✅ Continues until the correct number is guessed.
- 🔄 Allows multiple rounds.

🛠️ Technologies Used

☕ Java | ⌨️ Scanner | 🎲 Random
